เพลงไรวะ V9.2 — Mobile Fix

แก้ปัญหา iPhone / Safari ขึ้น “โหลดเพลงไม่ได้”:
- ลดจำนวน request พร้อมกันจาก 6 เหลือ 3
- จำกัดจำนวนศิลปินที่โหลดต่อรอบบนมือถือ
- เพิ่ม timeout และ retry ให้ iTunes JSONP
- ถ้ามีเพลงพอแล้วหยุดโหลดต่อ ลดโอกาส Safari ตัด request
- ต้องมีอย่างน้อย 6 เพลงจริงก่อนเริ่มเกม
- bucket ระดับความยากที่เพลงน้อยจะ fallback จาก pool กลาง
- แร็ปไทย / Kamikaze / T-POP ยังเลือกแยกศิลปินได้
- ไม่ได้เจนรูป
