ต่อโดเมนกับ GitHub Pages
แนะนำใช้ www เช่น www.yourdomain.com

GitHub: Repository > Settings > Pages > Custom domain > ใส่โดเมน > Save

DNS ถ้าใช้ www:
CNAME | Host: www | Target: YOUR-GITHUB-USERNAME.github.io

ถ้าใช้โดเมนหลัก yourdomain.com ให้เพิ่ม A records ที่ @:
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153

จากนั้นกลับ GitHub Pages รอ DNS check ผ่าน และเปิด Enforce HTTPS

ZIP นี้ยังไม่ใส่ CNAME จริง เพราะต้องรู้ชื่อโดเมนก่อน
